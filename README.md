# 명함 매니저

휴대폰으로 명함을 찍으면 이름·회사·직함·전화번호·이메일을 자동으로 읽어 저장하는 웹 앱입니다.
**가입, 로그인, API 키 없이** 브라우저만으로 동작합니다.

## 주요 기능

- **명함 촬영 → 자동 인식**: 브라우저 안에서 동작하는 무료 OCR([Tesseract.js](https://github.com/naptha/tesseract.js), 한국어+영어)로 글자를 읽고 항목별로 나눕니다.
  - 휴대폰 번호는 `전화번호`에, 사무실 번호·팩스·주소·홈페이지는 `메모`에 들어갑니다.
  - 저장 전에 확인 화면에서 고칠 수 있고, 인식된 원문도 볼 수 있습니다.
- **카메라**
  - HTTPS 주소(GitHub Pages 등)나 `localhost`: 화면 안에서 실시간 카메라로 촬영합니다.
  - 일반 `http://` 주소: 휴대폰 기본 카메라 앱이 열립니다.
- **사진 선택 / 직접 입력**
- **검색**: 이름, 회사, 전화번호, 메모
- **휴대폰 연락처 저장**: vCard(.vcf) 파일로 내보내 휴대폰 연락처에 추가합니다. 한 명씩 또는 전체를 내보낼 수 있습니다.
- **CSV 가져오기/저장**: 엑셀에서 열 수 있습니다(UTF-8 BOM 포함).
- **전화·문자·메일 바로가기**, 연락처 복사
- 다크 모드, 모바일 화면 지원

## 사용 방법

### 1. GitHub Pages로 배포 (추천: 휴대폰에서 실시간 카메라 사용 가능)

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**로 갑니다.
3. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소가 생깁니다. 휴대폰에서 이 주소를 엽니다.

### 2. PC에서 로컬 실행

[Node.js](https://nodejs.org/)만 있으면 됩니다. 따로 설치할 패키지는 없습니다.

```bash
npm start
```

- PC: http://localhost:8080
- 같은 Wi-Fi의 휴대폰: 실행할 때 화면에 나오는 `http://192.168.x.x:8080` 주소로 접속합니다. 이때는 기본 카메라 앱으로 촬영합니다.
- 포트 변경: `PORT=3000 npm start` (Windows PowerShell: `$env:PORT=3000; npm start`)

> `index.html`을 더블클릭해 바로 열어도 대부분 기능은 동작합니다. 다만 카메라와 OCR 엔진 로딩은 브라우저에 따라 막힐 수 있으므로 위 두 방법을 권장합니다.

## 데이터 저장 위치

- 명함은 **각 기기의 브라우저(localStorage)** 에만 저장됩니다. 서버나 외부로 전송되지 않습니다.
- 기기 사이에 옮기려면 **CSV 저장 → 다른 기기에서 CSV 가져오기**를 쓰세요.
- 브라우저 데이터를 지우거나 시크릿 모드로 쓰면 저장한 명함이 사라집니다. 주기적으로 CSV로 백업하세요.
- 사진은 브라우저 안에서만 처리합니다. 처음 인식할 때 OCR 엔진과 한국어 데이터(수 MB)를 CDN에서 내려받습니다.

## 인식 정확도

인식 과정에서 다음을 자동으로 처리합니다.

- **사진 보정**: 흑백 변환, 밝기 범위 자동 조정. 어두운 바탕에 흰 글씨인 명함은 반전해서 읽습니다.
- **방향 보정**: 옆으로 누운 사진이나 거꾸로 찍힌 사진은 90°/270°/180° 돌려 가장 잘 읽히는 방향을 고릅니다.
- **큰 글씨 다시 읽기**: 굵고 큰 이름처럼 OCR이 자주 틀리는 줄은 따로 잘라 적정 크기로 한 번 더 읽습니다.
- **잡음 제거**: 신뢰도가 낮은 줄과 의미 없는 짧은 글자는 버립니다(원문은 확인 화면에서 볼 수 있음).
- **글자 보정**: 전화번호 속 `O→0`, `l·I→1`, `S→5`, 이메일·홈페이지의 빠진 점(`co kr` → `co.kr`), 받침이 빠진 직함(`티자` → `팀장`)을 바로잡습니다.
- **항목 분리**: 휴대폰·직통·전화·대표번호·팩스, 부서+직함, 주소, 홈페이지를 구분합니다. 이름은 글씨 크기와 흔한 성씨를 기준으로 고릅니다.

그래도 디자인 글꼴, 손글씨, 반사·그림자가 심한 사진은 틀릴 수 있습니다. 밝은 곳에서 명함을 화면에 꽉 차게 찍고, 저장하기 전에 꼭 확인하세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML·CSS·JS 한 파일) |
| `server.js` | 로컬 실행용 정적 웹서버 (Node.js 기본 모듈만 사용) |
| `package.json` | `npm start` 실행 설정 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서비스하도록 하는 설정 |
| `other-versions/gemini-canvas.html` | 이전 버전: Gemini Canvas용 (Firebase + Gemini API, 설정값 직접 입력 필요) |
| `other-versions/claude-artifact.html` | 이전 버전: claude.ai 아티팩트용 (claude.ai 안에서만 동작) |
